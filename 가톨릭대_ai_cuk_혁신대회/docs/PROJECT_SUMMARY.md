# Special Everyone Project Summary

## 한 줄 요약

공유대학(CU12) 환경에서 장애학생의 강의 수강과 팀 협업 참여 장벽을 줄이기 위해 접근성 정보 구조, AI 자막, OCR 자료 점검, 확장 버튼 UI를 제안한 UX 리서치 및 서비스 기획 프로젝트입니다.

## 확인된 자료

- 리서치 기반 인사이트 도출 PPTX
- Special Everyone 발표자료 PDF
- 직접 제작한 공유대학 HTML 프로토타입
- CUK혁신 아이디어 경진대회 장려상 상장

## 포트폴리오에서 강조할 점

- 팀명: Special Everyone
- 수상: 제4회 CUK혁신 아이디어 경진대회 장려상
- 본인 역할: 발표 담당, HTML 프로토타입 직접 제작, 접근성 개선안 정리
- 핵심 주제: 공유대학 장애학생 접근성 개선
- 결과물: 발표자료, 리서치 포트폴리오, 웹 프로토타입, 상장
